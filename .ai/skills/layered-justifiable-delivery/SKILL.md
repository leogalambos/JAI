# Layered justifiable delivery

`tool-tier: orchestrate` (`Read, Grep, Glob, Bash, Task, Agent`)

This is the native orchestrator contract for `/layered` and its generated Codex
`workflow-layered` equivalent. The user supplies intent in ordinary language.
The parent handles the internal runtime; the user never needs to author protocol
JSON, choose internal professions, or call a runtime API.

Read [the native parent procedure](references/native-parent.md) before execution.
Use the canonical Gen2 layer registry and six question dimensions. Legacy
professional catalogue layer labels do not determine functional ownership.

## Inputs and initial state

Capture the operator's exact request bytes. Preserve explicit criteria verbatim
when provided. Otherwise use the same initial request bytes as the initial
criterion, labelled `same-verbatim-request`; do not invent additional L0 axioms.
Actual local setters derive measurable layer-owned criteria from inherited inputs.

Use the configured local iteration budget: ten minutes and at most three actual
reworks by default. A question's setter, author and reviewer share that incoming
unit; changing its own criteria does not reset the allowance or counter. Planning
waiting for downstream results does not consume an active integration window.
The local clock starts on actual physical dispatch, not grant preparation. Every
grant still has a finite lease. Aggregate task time/deadline caps are optional
and apply only when explicitly supplied. Timeout pauses work and reports the
actual unit/stage and pending physical observations to the operator; it creates
no business verdict or fabricated escalation. Extend a paused revision or stop
processing only under the actual operator instruction. An extension never
revives an old grant or resolves an uncertain physical call. These search limits
are not business requirements or proof that no solution exists.

For a new engagement, the internal `governed_layered.py start` path records inputs,
creates the structural L1 gateway and emits its actual native invocation intent.
It writes its machine-generated session/enrollment locators through the supported
runtime. Reuse explicit existing destinations and measurement-tool enrollment
where needed; do not introduce a replacement tool registry or withhold catalogue
resources. For an existing engagement, resume its recorded locator. Do not replace
blocked history with a new engagement under the same name.

## Native processing

Use only the active provider's native delegation tools. Execute the prepared model
controls and bounded invocation; record the actual tool handle and received body.
Never invent a native handle, staffing choice, professional answer or reviewer
verdict. Requested model controls are not proof of the served model or token usage.

Deliver the exact small prepared invocation message in the actual native call.
It names immutable resources instead of embedding the whole catalogue, protocol
and input history. Read only the resources needed for the current responsibility;
all catalogue entries and entitled neighboring parts remain available across
question labels. Use native Read only where that tool is actually available;
otherwise use only reviewed semantic carriers for exact delivered files under the
actual role ceiling, or have the parent relay exact bytes from the bound broker.
Such a carrier grants no general shell, arbitrary execution or reviewer fixing.
Do not replace the base message with a file-only stub or infer additional tools.
At native start preserve the actual provider observation separately from the
prepared host delivery manifest and prompt identities. Cold resume restores those
captured presentation bytes, never a newly rendered substitute for an old view.

Respect the delivered tool ceiling when collecting output. Choosers and nonfixing
reviewers return message bodies for parent capture. An author with Write/Edit
available may write its own artifact in authorized scratch; the parent captures
and proposes those exact bytes. Do not impose a blanket no-file restriction or
make native file reading a prerequisite for receiving the assignment.

The coordinating setter records its actual framing, criteria and closed owner
procedure for What, Why, How, Who, Where and When. Ordinary runtime steps derive

The owner's recorded procedure selects only an actually reviewed eligible result;

The host codec derives mechanical metadata without inventing professional facts.

## Changes, escalation and interruption

An input change belongs to its owning layer. Lower layers request it through
the adjacent protocol and cannot rewrite that owner's records. The owning entity
returns actual replacement decisions with exact affected uses and impacts.
Reuse unaffected current evidence; changed input versions never inherit old PASS.

Collect related escalation findings into the recorded bounded episode. By default
productive work in the affected layer stops. Speculative continuation requires
the existing explicit operator grant; do not add a bypass or infer independence
from an optimistic guess. Use the existing collection, relay, owner resolution
and reconciliation responsibilities. At L0, show the real conflicts, evidence,
unknowns, bounded options and exact proposed change. Inability to find a solution
within the search bounds does not prove impossibility.

Checkpoint and resume through journal-derived runtime state. Keep the foreground
Store warm across ordinary turns. A real process loss or code upgrade permits one
cold load; subsequent turns reuse established state. An exposed prepared call
without a confirmed handle is uncertain: reconcile that exact physical invocation
before acting. Do not spawn a
duplicate, guess its handle, refresh its budget or repeat an uncertain effect.

Human decisions are separate from continuing native work. Keyless inspection and
escalation dossiers must remain readable. A missing signing enrollment is reported
as a readiness gap, never filled by an invented signer. Only the operator signs
and submits reserved decisions outside the agent session. The runtime can prepare
the exact unsigned package and bind an actual returned public receipt; neither
operation submits the decision or grants acceptance/release.
