# Splunk platform data onboarding evidence

Splunk Enterprise and Splunk Cloud Platform. Qualify the exact deployment and ingestion components.

Check platform, forwarder, app and add-on compatibility and cloud tenancy restrictions when changing an input or upgrading.

Capture component versions, sanitized samples, expected fields and recency, deployment model and the boundary with ES-specific content.

Scope exclusions include enterprise Security-specific correlation, risk and security operations outputs.
