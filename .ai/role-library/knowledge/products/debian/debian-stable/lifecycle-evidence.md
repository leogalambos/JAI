# Debian Stable lifecycle evidence

Debian 13 Trixie stable at review. Assess older releases by their actual stable, oldstable or LTS phase.

Consult Debian release and security guidance when a suite changes phase, a package coverage claim changes, or a release upgrade is planned.

Preserve package origins, release identity, affected service state, approved upgrade procedure and tested recovery evidence.

Scope exclusions include testing and unstable branches, downstream distributions and unverified LTS package coverage.

[Debian Project public source](https://www.debian.org/releases/index.html)
