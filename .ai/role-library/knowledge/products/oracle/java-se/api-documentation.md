# Java API and JavaDoc evidence

Use the version-matched doclet specification for accessible APIs. Check generated documentation or doclint, including parameter, exception and return semantics. Use short ordinary comments for implementation notes and multiline JavaDoc for documented declarations.

- [JDK 25 JavaDoc Documentation Comment Specification](https://docs.oracle.com/en/java/javase/25/docs/specs/javadoc/doc-comment-spec.html)
- [Sun Java Code Conventions for comments, historical](https://www.oracle.com/java/technologies/javase/codeconventions-comments.html)
