# Android application engineering evidence

Record the SDK levels, exact Android Gradle Plugin, Gradle and JDK, target distribution, and representative devices. Check Android behavior changes for the actual target SDK. Verify restoration or loss of state, offline transitions, accessibility and performance where they affect the change. Link build identity, validation and any untested device classes. Confirm current store requirements at release planning.
