# Android application test automation evidence

Identify the risk tied to each local or instrumented test and record its data and environment. Include supported API levels, real and virtual device limits, permissions, lifecycle, locale or form factor as relevant. Record deterministic failures, intermittent failures and skipped cases separately. A passing narrow suite establishes only its observed coverage.
