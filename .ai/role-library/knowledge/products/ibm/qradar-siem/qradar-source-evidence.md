# IBM QRadar SIEM source integration evidence

Use this reference when onboarding a log source, reviewing event parsing or
accepting a source or deployment compatibility claim for on-premises 7.6.0.

Record the exact QRadar fix level, deployment, source product and version,
collector, collection protocol, log source identifier and DSM version.
Verify the applicable supported source and hardware or virtual-software
boundary before proposing or validating a configuration.

Choose representative authorized events with expected source attribution,
fields and classification. Keep actual collection, parsing and normalization
observations separate from intended deployment behavior. When events remain
unknown or fields cannot be mapped, state the remaining gap, affected
coverage and accountable owner. Use redacted event evidence and follow the
existing change and evidence controls.
