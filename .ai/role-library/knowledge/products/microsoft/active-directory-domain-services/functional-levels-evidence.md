# Active Directory Domain Services functional levels evidence

Windows Server 2025 AD DS and verified common Windows Server 2022 AD DS operation at compatible functional levels.

Recheck the supported matrix, controller inventory and recovery prerequisites before planning a controller upgrade or functional-level change.

Capture recorded levels, controller versions, health and replication evidence, verified recovery readiness and a separate approval for any level change.

Scope exclusions include microsoft Entra ID, unverified functional-level raises and forest recovery execution without approval.
