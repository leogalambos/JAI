# Windows Server LTSC operations evidence

Windows Server 2025 LTSC. Windows Server 2022 is in scope only for individually verified common behaviors.

Check the exact servicing build, support lifecycle and feature documentation when advising on patching, upgrade or cross-version operation.

Separate confirmed common operations from release-specific features and record the component, build and applicable evidence for each.

Scope exclusions include unverified 2025 feature parity, unsupported upgrade paths and functional-level decisions outside an AD DS mandate.
