# Fictional policy proposal criteria

- Trace the proposal to the exact brief and distinguish stated inputs,
  assumptions, planned measures and observed evidence.
- Cover accountable ownership, time limits, independent review, revocation,
  exceptions and the evidence needed before implementation.
- Preserve separation of requesting, authoring, reviewing and reserved human
  decisions. Each layer chooses its own catalogue professions and method.
- Keep source and output versions immutable; changed requirements must not
  inherit earlier review or permission automatically.
- Explain unresolved conflicts, missing inputs and the current justification
  using actual recorded versions. Do not fabricate test PASS or measurements.
- Treat a completed run, professional support, human acceptance and release
  permission as separate facts. This fictional exercise grants none of them.
