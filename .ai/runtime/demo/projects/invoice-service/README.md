# invoice-service

Creates, stores and reports customer invoices for the billing team.

## Features

- create invoices with line items and automatic volume discount
- orders of 1000 EUR or more get a 5% discount
- look up a customer's invoices
- delete an invoice (owner only)
- CSV export of invoices for the accounting system

## Running

Requires Python 3.6. Run the tests with `python -m pytest`.
