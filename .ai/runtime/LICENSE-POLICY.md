Source code uses a compact SPDX notice instead of embedding the full
license. Executable scripts keep their shebang on the first line.

headers when those headers would consume prompt context or reduce the
semantic signal. JSON and other formats without comments inherit the

third-party resources. The pinned ArchiMate relationship data and exchange

copyright notices. The directory contains the complete `License.txt` and
`provenance.json` identifying source revision, paths and digests. Its JAI-authored
provenance record remains under the package licence. No Archi application or
restricted standard publication is bundled.
