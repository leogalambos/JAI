# Bundled expert reference examples

The complete version 2.2.0 library contains 135 English Markdown examples:
45 document families at simple, medium and complex levels. This revision
preserves all 96 established examples byte-for-byte, including all 30 proposal
references, and adds 39 engineering, transformation, security assessment and
DevSecOps/AppSec examples. All distributed Markdown bytes match the supplied
version 2.2.0 documents.

These are AI-authored proposed professional illustrations. Organisations,
measurements, evidence, prices, offers and execution results are fictional.
They are not human-approved standards, customer evidence, completed tests,
executed offers, legal agreements or JAI L0 authority acts.

`index.json` records the integrity of these public-synthetic files. Explicit
`expert-reference-bindings.json` mappings connect their original section
anchors to actual registered DCS units, including proposed specializations.
A proposed anchor establishes addressability, never approval or an active
production control. Content adequacy, evidence quality and professional
acceptance remain separate questions. The normative DCS registry and existing
JAI governance always take precedence over reference text. Supplied manifest
mapping statuses describe source-pack structure, not verified human approval.

Validate offline with:

```sh
python3 .ai/runtime/tools/expert_references.py validate --root . --all
```

Keep user, organisation and engagement overrides outside this directory.
See the maintained MkDocs guides for family mappings, front matter,
context and audience selection, installation, restoration and limitations.
