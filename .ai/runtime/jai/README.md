# Justifiable AI Core — 26.10.4

The six-layer Justifiable AI model is the single normative top-level architecture of AI IT House.
Human Authority is an external L0 boundary and is not a seventh JAI layer.

Artifact, SABSA, EA, Publication and Runtime are profiles or enforcement mechanisms of this core.
They may be authoritative only within their declared scope. They must not introduce a competing global
source of truth. Canonical semantic identity is preserved across profiles; the fabric is an append-only
assurance ledger over canonical object references and hashes.

Compatibility is forward-only: 26.10.0 Artifact Contract v2 and
26.10.1–26.10.3 JAI/v3 structures remain readable/migratable. 26.10.4
is the only native production write namespace. Historical audit records
are never rewritten.
