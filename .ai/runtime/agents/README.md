# Provider-neutral advisory agent metadata

Owner: JAI runtime maintainers. Review trigger: a changed agent contract consumer.

`agent-contracts.json` and the retained runtime bindings support catalogue
validation, provider projections and operator diagnostics. Their historical
`jai.layer` or `primary_layer` classification does not authorize P05 ownership,
confine a profession to a layer, or let a neighbor choose local staff.

Governed execution instead uses the Store's exact functional assignment,
current global capability policy, actual captured local `select_execution`
decision and fresh work context. All layers intrinsically have the common public
role catalogue. Broker rights are constrained by the mandate, selected tool-tier
intersection, duties, current inputs and finite resources.

The Markdown agent instructions describe professional conduct; they are not
execution attestations. Native Codex/Claude execution is unsupported by the
current confined adapter. Old metadata, an agent label or a provider projection
cannot substitute for current selection/work provenance or independent review.
