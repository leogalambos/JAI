# Historical archive

This tree preserves retired processing, release pipelines, workflow instructions,
and their historical tests. It is excluded from active test discovery and
release bundles. Its commands are not supported executable entry points.

Archived material provides historical context only. It cannot verify a new
state, transfer acceptance, restore permissions, or authorize release. Start a
new format-3 engagement with explicit current inputs; no migration or
compatibility execution route is provided.

The archive includes original HEAD versions of replaced or deleted tests and
working-tree snapshots of mixed files taken before their retired sections were
removed. It is not a single executable release snapshot. Retained professional
resources and current secure packaging utilities remain outside this archive.
