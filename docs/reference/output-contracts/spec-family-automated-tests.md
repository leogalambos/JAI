### Required information (MUST)

**`family/automated-tests.automated_test_scope`** — `array`

- Trace executable cases and reusable test abstractions to requirements, risk coverage, deterministic data and environment assumptions.
- Each executable case identifies the covered behaviour/risk, deterministic setup/data, stimulus, expected assertion and relevant environment assumptions.
- **Professional basis:** [source](https://www.iso.org/standard/79429.html); [source](https://doi.org/10.6028/NIST.SP.800-218) (informed-by; not a verbatim standard requirement).

**`family/automated-tests.automated_test_execution`** — `array`

- Give reproducible invocation, assertions, expected outcomes and failure diagnostics; distinguish test definitions from evidence of executed runs.
- Give the command, required dependencies and failure diagnostics; distinguish a case definition from an observed execution result for an exact product revision.
- **Professional basis:** [source](https://www.iso.org/standard/79429.html); [source](https://doi.org/10.6028/NIST.SP.800-218) (informed-by; not a verbatim standard requirement).

- **Professional basis:** [source](https://www.iso.org/standard/79429.html); [source](https://doi.org/10.6028/NIST.SP.800-218) (informed-by; not a verbatim standard requirement).
