# Glossary

**Artifact Contract v3** — The current production composition contract for an artefact. It binds purpose, semantics, justification, design, realisation, evidence, lifecycle and traceability to JAI responsibilities.

**Canonical semantic identity** — The stable identity owned by the JAI semantic model and referenced by scoped profiles such as SABSA, EA, publication and the Fabric assurance ledger.

**Context digest** — SHA-256 digest of a rendered/canonical layer context packet. A returned layer result must declare the matching digest before it can be ingested.

**Escalation** — Movement of an unresolved problem one JAI layer upward. Escalations may not move sideways/downward; authority-sensitive conditions remain sticky as they ascend.

**Evidence drift** — A change in the content or status of evidence that had supported a product. Strict release eligibility can be invalidated when recorded evidence no longer matches its captured digest/current status.

**Fabric** — The Justifiable Fabric append-only, hash-chained assurance ledger used for consequential layered engagements. It records contracts, attempts, evidence, reviews, conflicts, escalations and authority/release state; it is not the global semantic source of truth.

**Human Authority (L0)** — External authority boundary above JAI L1. L0 is not a seventh AI layer; agents can prepare and record a decision path but cannot synthesize human authority.

**JAI (Justifiable AI) core** — The six-layer normative architecture of AI IT House: Intent and Context; Meaning and Domain Model; Reasoning, Policy and Control; Solution Design; Realisation and Tooling; Execution and Evidence.

**Layered engagement** — A supervised consequential-work episode opened through `/layered` in which requirements descend through typed contracts and evidence/review/escalation return upward under bounded recovery rules.

**Paper mode** — Fabric justifiability mode that mirrors the published formal/research definition closely enough to inspect it. It is not the production release standard.

**Projection manifest** — The controlled mapping from semantic source content to an audience-specific publication model, including JAI lineage and projection/render identity.

**Publication archetype** — A target deliverable profile such as Decision Paper or Architecture Review Board Pack.

**Reformulation** — A new generation of a requirement because the previous requirement is infeasible or inadequate. Only the layer that owns/issued that requirement may reformulate it.

**Rework** — Another attempt at the same requirement. Rework must preserve material semantic fields and is bounded per contract lineage.

**Semantic hash** — SHA-256 identifier of an approved semantic source/model snapshot.

**Strict justifiability** — Production-oriented Fabric release standard requiring stronger evidence/review conditions than paper-mode justifiability.

**Unified Lifecycle GA** — Release objective completed in 26.10.4: JAI is the normative architecture and Artifact/SABSA/EA/Publication/Runtime use profile-native current writes and shared lifecycle/identity rules.

**Workflow** — Canonical operating sequence connecting roles, stages, gates and outcomes.
