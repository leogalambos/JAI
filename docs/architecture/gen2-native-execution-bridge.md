# Native provider execution

JAI uses the active Claude Code or Codex session's native delegation facilities.
The native parent coordinates professional entities and the shared runtime;
users do not launch nested provider clients or construct worker transport files.

## Shared professional contract

The parent obtains an issued task-specific context, delegates it with the
selected professional instructions and captures the actual returned result.
The runtime binds that capture to the issued assignment and context before
admitting its semantic effects.

Selection of specialties and model resources is separate from the work result.
A plan can be reused while its governing inputs and assignments remain unchanged.
Do not repeat a completed professional selection solely to advance a mechanical
continuation step.

## Compact contexts

Each task receives relevant input sections and immutable attachment references.
Author and reviewer use isolated contexts. The full engagement history and every
catalogue definition are not embedded into every prompt. Missing information is
requested explicitly instead of guessed from an unrelated conversation.

The complete catalogue remains available for local staffing; compact context
assembly must not become a restrictive role whitelist.

## Durable continuation

Issued identities, actual captures and admitted results are recorded. On restart,
reconcile the existing prepared intent or bound handle and retain uncertain work
as uncertain until observed. Do not respawn completed work or fabricate that an
interrupted provider call terminated successfully.

Provider capabilities and effective sandbox permissions remain deployment
dependencies. A shipped projection or readable instruction is not proof that a
particular provider session has loaded it or executed professional work.
